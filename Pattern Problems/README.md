8. Inverted Full Pyramid
9. Hollow Pyramid
10. Diamond Pattern
11. Hollow Diamond

13. Floyd's Triangle
14. Pascal's Triangle
15. Number Triangle
16. Palindrome Number Pattern
17. 0-1 Triangle
18. Alphabet Triangle
19. X Pattern
20. Spiral Matrix Pattern
